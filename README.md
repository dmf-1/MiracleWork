# silver-potato
A sample blog based on the 
https://github.com/learning-zone/website-templates repo

# HTML parser
* Streamlit form that allows posting (based on site templates)
* It uses beautifulsoup to parse HTML and create new publications
* It creates a new post and adds it to the home page, allowing users to use github pages as a personal blog

```
# To run
git clone 'https://github.com/rpgv/silver-potato.git'
cd silver-potato
uv run streamlit run main.py
```
# Make it yours
* The template is basic and 'professional' by default
* You can change the backgrounds of each page by:
  * Loading images through the image loader in the *side-bar*
  * Manually uploading tem to github -> then updating code on local run
  * Images should follow this name structure:
      * 'about-bg.png'  - to replace the About me background image
      * 'contact-bg.png'  - to replace the Contact background image
      * 'home-bg.png'  - to replace the Home background image
   
* To change the content of each page you can navigate the tabs in the main page

# Publications
* Your posts should be written in Markdown
* It will then be parsed into HTML
* Images should be added via the image uploader - it generates a path that should be copied and pasted in the main content form section
